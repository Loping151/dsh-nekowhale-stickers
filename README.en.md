## ✨ Features

<table>
<tr>
<td width="33%" valign="top">
<h4>📚 Sticker knowledge</h4>
Every sticker is annotated: situation tags, a description of the motion, the meme it plays on, and for the duo set the <b>direction</b> (who does what to whom), so the model barely needs its own vision. About 60 tokens stay in context.
</td>
<td width="33%" valign="top">
<h4>🔍 Mood search</h4>
Scored search over moods and situations with Chinese partial matching; light shuffling against repeats.
</td>
<td width="33%" valign="top">
<h4>🎨 Local templates</h4>
想 / 举牌 / 葱卷 / 上联 / 下联 / 抱: make text stickers locally.
</td>
</tr>
<tr>
<td valign="top">
<h4>🔄 Incremental sync</h4>
Pulls the latest version when the art is updated; lazy downloads by default.
</td>
<td valign="top">
<h4>🎛️ Self curation</h4>
The agent may browse and switch stickers on or off, or keep a small chosen set; your config black / white lists always win.
</td>
<td valign="top">
<h4>🔌 Generic interfaces</h4>
A cordis service <code>stickers</code>, <code>[sticker:name]</code> reply marks, an MCP server, a CLI and a public JSON. No framework lock-in.
</td>
</tr>
<tr>
<td colspan="3" valign="top">
<h4>🐋 Web pet</h4>
The kiriyuki.com 大肥鱼 web pet appears in the corner of the dsh web UI. It runs in a separate cross-origin iframe and never touches dsh sessions; <code>pet: false</code> turns it off.
</td>
</tr>
</table>

## 🚀 Install

```sh
dsh plugin --profile web add dsh-nekowhale-stickers
```

Then restart `dsh web`. On dsh 0.2 you can also enter `dsh-nekowhale-stickers` under **Plugins → Add plugin** in the web sidebar. A local `.tgz` from `pnpm pack` works too.

## ⚙️ Configure

Easiest: in the dsh web UI sidebar open **Plugins → 大肥鱼表情包** (dsh 0.1.x: **Settings → Plugins → 大肥鱼表情包**), change options and Save. They apply immediately, no restart.

Defaults can also go in the profile's `cordis.patch.yml`; values saved in the web UI override them:

```yaml
- id: nekowhale-stickers
  config:
    promptMode: hint        # skill | hint | index | off
    frequency: normal       # rare | normal | often
    blacklist: [tag:舌吻]   # id, file stem, code, name, or pack: / tag: / emotion: / group: rules
```

| Key | Default | Meaning |
|---|---|---|
| `packs` | both sets | sets to serve |
| `autoSync` | `lazy` | `startup` mirror all in background · `lazy` download on first use · `off` offline |
| `persona` | `self` | `self`: the agent is 大肥鱼 and the stickers are its own expressions (fits DeepSeek); `neutral`: a third-party pack |
| `promptMode` | `skill` | how much stays in the prompt; `index` lists enabled stickers, meant for a small allowlist |
| `agentCuration` | `true` | let the agent curate with `sticker_manage` |
| `templates` / `banwords` | `true` | templates; the website's word filter |
| `returnImageToModel` | `false` | attach the picture for the model to see (image tokens) |
| `pet` | `true` | show the 大肥鱼 web pet in the web UI; `false` turns it off |
| `petHeight` / `petBubbles` | `211` / `true` | pet size (height in pixels), speech bubbles (off saves about 1.5 MB) |

## 🧰 Tools

| Tool | Purpose |
|---|---|
| `sticker_search` | find stickers, one line each: `name｜emotion｜tags｜direction` |
| `sticker_send` | returns a Markdown image line to paste into the reply; an emotion word picks a random one |
| `meme_render` | render a template |
| `sticker_manage` | browse, info, enable / disable, mode, credit, sync |

## 🤝 Use from other plugins and frameworks

Four generic interfaces:

- **cordis service** (other dsh plugins, e.g. a QQ bridge): `inject: ['stickers']`, then `ctx.stickers.search()` / `.file()` / `.url()` / `.render()`.
- **Reply marks**: in plain-text replies write `[sticker:name]`, or an emotion such as `[sticker:开心]` for a random one; a bridge splits the reply with `parseReply()`. NapCat / OneBot shows a GIF as a sticker only with `sub_type: 1` on the image segment.
- **MCP** (LangBot, NoneBot / AstrBot LLM plugins, Claude / Cursor style clients, ...):
  ```json
  { "command": "npx", "args": ["-y", "dsh-nekowhale-stickers", "mcp"] }
  ```
  Tools return a local path and a public URL; the host sends the file.
- **Data and CLI** (any language): [`meta/nekowhale.json`](meta/nekowhale.json) (live at `https://kiriyuki.com/meme/kit/nekowhale.json`), or
  ```sh
  npx dsh-nekowhale-stickers search 摸鱼
  npx dsh-nekowhale-stickers index
  npx dsh-nekowhale-stickers render 大肥鱼举牌 今天也要开心 -o sign.gif
  ```

You can also build your own integration on top of this repository.

## 🛠️ Develop

```sh
pnpm install && pnpm build
node tools/dev/smoke.mjs /tmp/data      # run every tool against a fake ctx
```

- `tools/annotate/`: labelling pipeline, frame contact sheets → per-sticker vision annotation → `build_meta.py` → `meta/nekowhale.json`.
- `tools/art/`: scripts that compose the hero and showcase images (background plate + real sticker frames + Live2D portrait); the resulting images are hosted by kiriyuki.com.
