## 🚀 安装

```sh
dsh plugin --profile web add dsh-nekowhale-stickers
```

重启 `dsh web` 即可。dsh 0.2 也可以在网页侧栏 **插件 → 添加插件** 里填 `dsh-nekowhale-stickers`。也可以安装本地打包的 `.tgz`（`pnpm pack`）。

## ⚙️ 配置

最简单的方式：dsh 网页侧栏打开 **插件 → 大肥鱼表情包**（dsh 0.1.x 在 **设置 → 插件 → 大肥鱼表情包**），改完点保存，立即生效、无需重启。

也可以在 profile 的 `cordis.patch.yml` 里写默认值，网页里的设置会覆盖它：

```yaml
- id: nekowhale-stickers
  config:
    promptMode: hint        # skill | hint | index | off
    frequency: normal       # rare | normal | often
    blacklist: [tag:舌吻]   # id、文件名、编号、名字，或 pack: / tag: / emotion: / group: 前缀
```

| 项 | 默认 | 说明 |
|---|---|---|
| `packs` | 两套 | 要使用的套组 |
| `autoSync` | `lazy` | `startup` 启动时后台全量同步 · `lazy` 用到才下载 · `off` 完全离线 |
| `persona` | `self` | `self`：模型就是大肥鱼，表情是它自己的表情（适合 DeepSeek）；`neutral`：当作第三方表情包 |
| `promptMode` | `skill` | 常驻提示的多少；`index` 会列出已启用表情，适合配合 allowlist 只挑几十张 |
| `agentCuration` | `true` | 允许 agent 用 `sticker_manage` 自选表情 |
| `templates` / `banwords` | `true` | 模板开关；与网站一致的屏蔽词过滤 |
| `returnImageToModel` | `false` | 把图片附给模型看（消耗图像 token） |
| `pet` | `true` | 网页界面里显示大肥鱼桌宠；`false` 关闭 |
| `petHeight` / `petBubbles` | `211` / `true` | 桌宠大小（高度，像素）、对话气泡（关掉可少加载约 1.5 MB） |

## 🧰 工具

| 工具 | 作用 |
|---|---|
| `sticker_search` | 按情绪 / 场景找表情，每条一行：`名字｜情绪｜标签｜方向` |
| `sticker_send` | 返回一行 Markdown 图片，模型原样放进回复；传情绪词则随机取一张 |
| `meme_render` | 用模板生成表情 |
| `sticker_manage` | 浏览、详情、开关、模式、出处、同步 |

## 🤝 在其他插件和框架里使用

提供四种通用接口：

- **cordis 服务**（dsh 内的其他插件，如 QQ 桥接）：`inject: ['stickers']`，然后 `ctx.stickers.search()` / `.file()` / `.url()` / `.render()`。
- **回复标记**：纯文本回复里写 `[sticker:名字]`，或 `[sticker:开心]` 这类情绪词（同类随机取一张），桥接插件用 `parseReply()` 拆成文字与图片。NapCat / OneBot 发 GIF 时给图片段加 `sub_type: 1` 才会按表情显示。
- **MCP**（LangBot、NoneBot / AstrBot 的 LLM 插件、Claude / Cursor 类客户端等）：
  ```json
  { "command": "npx", "args": ["-y", "dsh-nekowhale-stickers", "mcp"] }
  ```
  工具返回本地路径和公网 URL，由宿主自己发文件。
- **数据与 CLI**（任何语言）：[`meta/nekowhale.json`](meta/nekowhale.json)（线上 `https://kiriyuki.com/meme/kit/nekowhale.json`），或
  ```sh
  npx dsh-nekowhale-stickers search 摸鱼
  npx dsh-nekowhale-stickers index
  npx dsh-nekowhale-stickers render 大肥鱼举牌 今天也要开心 -o sign.gif
  ```

亦可基于本仓库重新开发。

## 🛠️ 开发

```sh
pnpm install && pnpm build
node tools/dev/smoke.mjs /tmp/data      # 用假 ctx 跑一遍全部工具
```

- `tools/annotate/`：标注流程，抽帧拼图 → 多模态模型逐张标注 → `build_meta.py` 合并成 `meta/nekowhale.json`。
- `tools/art/`：头图与展示图的合成脚本（背景底板 + 真实表情帧 + Live2D 立绘）；成品图片由 kiriyuki.com 托管。
